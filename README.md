# Snakes and Ladders

### Requisiti: Java 21 o superiore

### Utilizzo
1. Clonare il repository: `git clone https://github.com/alexscrivano/snakes_and_ladders.git`
2. Navigare nella cartella dei file jar: `cd .\out\artifacts\SnakesAndLadders_jar\`
4. Eseguire il file .jar: `java -jar .\SnakesAndLadders.jar`

Una volta eseguito si aprirá una finestra per la selezione di:
- num. di giocatori;
- num. di dadi;
- tipologia di regole;
- dimensioni del tabellone;

Una volta selezionate, basta premere il pulsante "next" per procedere con la simulazione.
